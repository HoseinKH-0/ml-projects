# Retail Store Sales Data Cleaning
- - -
## توضیحات
در این پروژه، که مربوط به دیتاست فروش محصولات یک فروشگاه هست این دیتاست شامل انواع داده های نامناسب و داده های گمشده بود که با Pandas پاک سازی کردم
- - -
# دیتاست
دیتاست retail_store_sales که یک دیتاست مربوط به فروش محصولات یک فروشگاه هست که شامل 11 ستون:

- Transaction ID: شناسه‌ی یکتای هر تراکنش
- Customer ID: شناسه‌ی مشتری‌ای که خرید کرده
- Category: دسته‌بندی محصول
- Item: محصولی که خریداری شده
- Price Per Unit: قیمت هر واحد از محصول
- Quantity: تعداد واحدهای خریداری‌شده
- Total Spent: مبلغ کل پرداخت‌شده برای آن تراکنش
- Payment Method: روش پرداخت
- Location: محل انجام خرید
- Transaction Date: تاریخ تراکنش
- Discount Applied: اینکه برای تراکنش تخفیف اعمال شده یا نه
- - -
# مشکلات دیتاست

- داده‌های گمشده‌ی زیادی در دیتاست وجود داشت
- نوع داده‌ی برخی ستون‌ها نامناسب بود
- - -
# Cleaning Process
- مقادیر گمشده‌ی ستون‌های Total Spent، Quantity، Price Per Unit، Discount Applied و Transaction Date را بررسی کردم
- برخی داده های گمشده ی ستون های Total Spent و Quantity و Price Per Unit رو با استفاده از رابطه ریاضی بین شون به دست آوردم
- داده هایی که با این رابطه ی ریاضی قابل حساب نبودند را حذف کردم
- ستون Discount Applied را با استفاده از astype به 0 و 1 تبدیل کردم
- نوع داده‌های نامناسب رو با استفاده از توابع to_datetime و astype اصلاح کردم
- - -
# Validation
- هیچ مقدار خالی و نامعتبری در دیتاست باقی نمانده
- نوع داده ها اصلاح شدند
- رابطه ی ریاضی Total Spent = Quantity * Price Per Unit درست و برقرار است
- هیچ داده ی تکراری وجود ندارد
- در نهایت دیتاست تمیز را ذخیره کردم
