# ML Projects
- - -
این ریپو برای ساخت و جمع‌آوری پروژه‌های مختلف در زمینه‌ی Machine Learning و Data Science ساخته شده است.

هدف اصلی این پروژه‌ها، تمرین مهارت‌ها و ساخت نمونه‌کارهای مختلف است. در ابتدا پروژه‌ها ساده‌تر هستند و بیشتر روی مهارت‌هایی مثل Data Cleaning تمرکز دارند و به مرور با یادگیری بیشتر، پروژه‌ها پیچیده‌تر و چالش‌برانگیزتر می‌شوند.
- - -
هر پروژه یک مهارت یا موضوع مشخص را تمرین می‌کند و نتیجه‌ی آن به صورت یک پروژه‌ی مستقل در این ریپو قرار می‌گیرد.

این ریپو در کنار مسیر یادگیری اصلی من در ریپوی [ml-learning-journey](https://github.com/HoseinKH-0/ml-learning-journey) قرار دارد.
