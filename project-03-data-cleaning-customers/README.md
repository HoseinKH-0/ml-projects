# Customer Data Cleaning
- - -
## توضیحات
در این پروژه دیتاست اطلاعات مشتریان را با Pandas پاک سازی کردم.
دیتاست شامل داده های گمشده، داده های تکراری و ستون هایی با نوع داده ی نامناسب بود که آن ها را بررسی و اصلاح کردم
- - -
# دیتاست
دیتاست Customers که یک دیتاست مربوط به اطلاعات مشتریان بود شامل 9 ستون:

- customer_id: شناسه ی مشتری
- name: نام مشتری
- age: سن مشتری
- gender: جنسیت مشتری
- state: ایالت محل زندگی مشتری
- signup_date: تاریخ ثبت نام مشتری
- email: ایمیل مشتری
- phone_number: شماره ی تلفن مشتری
- subscribe: وضعیت عضویت مشتری
- - -
# مشکلات دیتاست

- وجود مقادیر گمشده در ستون های age و state
- وجود ردیف های تکراری
- نامناسب بودن نوع داده ی signup_date
- متنی بودن مقادیر ستون های gender و subscribe
- - -
# Cleaning Process
- مقادیر گمشده ی ستون age رو با میانگین پر کردم
- مقادیر گمشده ی ستون state را با استفاده از mode پر کردم
- مقادیر ستون gender رو با استفاده از map به 0 و 1 تبدیل کردم
- مقادیر ستون subscribe رو با استفاده از map به 0 و 1 تبدیل کردم
- نوع داده ی ستون signup_date رو با استفاده از to_datetime به تاریخ تبدیل کردم
- ردیف های تکراری رو با استفاده از drop_duplicates حذف کردم
- - -
# Validation
- هیچ مقدار گمشده‌ای در دیتاست باقی نمانده
- هیچ ردیف تکراری در دیتاست باقی نمانده
- نوع داده‌ی ستون‌های موردنظر اصلاح شده است
- دیتاست تمیزشده در فایل clean_customers.csv ذخیره شده است
