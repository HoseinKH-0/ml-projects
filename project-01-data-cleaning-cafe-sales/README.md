# Cafe Sales Data Cleaning
- - -
## توضیحات
در این پروژه دیتاست مربوط به فروش کافه را که شامل مقادیر نامعتبر، داده های گمشده و انواع داده ی نامناسب بود، با استفاده از Pandas پاک سازی کردم.
- - -
# دیتاست
دیتاست dirty_cafe_sales که یک دیتاست مربوط به فروش کافه هست شامل 8 ستون:

- Transaction ID: شناسه‌ی یکتای هر تراکنش
- Item: محصول خریداری شده
- Quantity: تعداد محصول خریداری شده
- Price Per Unit: قیمت هر واحد از محصول خریداری شده
- Total Spent: مبلغ کل پرداخت شده برای آن تراکنش
- Payment Method: روش پرداخت مثلا Cash
- Location: محل انجام تراکنش، مثل In-store یا Takeaway
- Transaction Date: تاریخ انجام تراکنش
- - -
# مشکلات دیتاست

- مقادیر نامعتبری مثل ERROR و UNKNOWN در برخی ستون‌ها وجود داشت
- داده‌های گمشده‌ی زیادی در دیتاست وجود داشت
- نوع داده‌ی برخی ستون‌ها نامناسب بود
- - -
# Cleaning Process
- مقادیر نامعتبری مثل ERROR و UNKNOWN رو به NaN تبدیل کردم
- داده های گمشده ی ستون های Location و Payment Method و Item رو با استفاده از mode به دست آوردم
- مقادیر گمشده‌ی ستون‌های Total Spent، Quantity و Price Per Unit را با استفاده از رابطه‌ی ریاضی بین آن‌ها بازسازی کردم
- داده هایی که با این رابطه ی ریاضی قابل حساب نبودند را حذف کردم
- تاریخ های گمشده رو حذف کردم
- نوع داده‌های نامناسب رو با استفاده از توابع to_numeric و to_datetime اصلاح کردم
- - -
# Validation
- هیچ مقدار خالی و نامعتبری در دیتاست باقی نمانده
- نوع داده ها اصلاح شدند
- رابطه ی ریاضی Total Spent = Quantity * Price Per Unit درست و برقرار است
- هیچ داده ی تکراری وجود ندارد
- در نهایت دیتاست تمیز را ذخیره کردم
